## 📸 अपनी PNG फ़ोटो कैसे लगाएं (How to Add Your Photo)

वेबसाइट पर आपकी ट्रांसपेरेंट कट-आउट PNG फ़ोटो लगाने के **2 बहुत आसान तरीके** हैं:

### तरीका 1 (Instant): ब्राउज़र में बटन दबाएं
1. वेबसाइट को ब्राउज़र में खोलें।
2. हीरो सेक्शन में फ़ोटो पर बने **"Drop / Click Your PNG Photo Here"** बटन पर क्लिक करें।
3. अपने कंप्यूटर से अपनी कोई भी PNG फ़ोटो चुन लें। वह तुरंत लाइव दिख जाएगी!

### तरीका 2 (Permanent for GitHub / Hosting):
1. अपनी ट्रांसपेरेंट बैकग्राउंड वाली PNG फ़ोटो का नाम **`photo.png`** रखें।
2. उस फ़ोटो को इसी फ़ोल्डर (`d:\ai video folder\raw footage'\`) में `index.html` के बगल में रख दें।
3. वेबसाइट रिफ्रेश करते ही आपकी फ़ोटो अपने आप सेंटर स्टेज में लग जाएगी!

## 🚀 GitHub Pages पर लाइव करने का तरीका (Deploy to GitHub)

```bash
git init
git add index.html photo.png README.md
git commit -m "feat: launch worksruthi style portfolio"
git branch -M main
git remote add origin https://github.com/<YOUR-USERNAME>/my-portfolio.git
git push -u origin main
```

फिर GitHub पर **Settings → Pages → Branch: main** सेलेक्ट करके सेव करें। वेबसाइट मुफ़्त में दुनिया भर के लिए लाइव हो जाएगी!
